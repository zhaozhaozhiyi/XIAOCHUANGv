## 0.23 小版本路径

- `0.23.0`：规划包与文档列车入口，已完成文档归档、需求入口收敛和优先级重排。
- `0.23.1`：短剧 AI-first 主流程修正版，已封版，完成源稿理解、改编策略、真实分集蓝图和项目公共资产引用的最小闭环。
- `0.23.2`：画布可信闭环验收版，已封版，完成资产闭环、上传闭环、生成历史、来源追溯和最小快速生成验收。
- `0.23.3`：下一交付版本，画布 AI 对话与镜头体验增强版，聚焦 3 个最小 Skill、角色/场景端口、合成导出节点和镜头主线体验。

## 0.23 范围摘要

- 短剧移除“方案草稿”主流程对象，改为源稿理解、改编策略、分集蓝图、试播正文、单集工作台生产。
- 单集工作台明确项目公共主档、单集引用与覆写、镜头私有产物三层资产逻辑。
- 画布产物真实进入资产体系。
- 画布上传、生成历史、来源追溯形成可信闭环。
- 画布对话栏开放最小 Skill 闭环：`create_nodes`、`update_node`、`add_to_context`。
- 待评估事项集中维护在 `待办评估清单.md`，避免散落在旧报告和历史 PRD/TRD 中。

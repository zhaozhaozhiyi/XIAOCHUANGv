**文档类型**: 模块 PRD
**状态**: draft
**修订号**: r2

## 1. 文档目的

本文档用于明确资产模块的页面布局、卡片规格、筛选搜索、来源跳转、预览播放、下载能力和验收标准。

本文档应直接支撑以下工作：

- 产品确认资产模块到底展示什么、不展示什么
- 设计输出资产页结构、卡片样式和空状态
- 前端按分类、搜索、卡片、来源跳转和播放下载交互开发
- 后端明确资产对象、来源字段和入库链路
- 测试按角色、场景、媒体三大分区验收

## 2. 模块定位

资产模块是统一查看资产的页面，不是资产生产页面，也不是资产回用调度中心。

资产模块要解决的问题是：

- 已经生成的结果散落在快速成片、短剧、画布等不同模块里，不方便集中查看
- 用户不知道一个资产来自哪里
- 用户需要统一查看角色、场景、图片、视频、音频

当前版本资产模块不承担以下职责：

- 不承担回用到短剧或画布的业务入口
- 不承担再次发起生成
- 不承担项目管理
- 不承担资产拖拽回业务模块

## 3. 页面范围

当前版本资产模块只有一个主页面：

| 页面 | 页面目标 | 进入方式 | 页面结果 |
|------|----------|----------|----------|
| 资产页 | 统一查看角色、场景、图片、视频、音频资产，并追踪来源 | 首页、快速成片、短剧、画布、侧边入口 | 资产浏览、来源跳转、下载、播放、预览 |

## 4. 页面布局

### 4.1 总体布局

资产页采用“页面标题区 + 一级分类 Tab + 二级媒体 Tab + 搜索筛选区 + 列表区”的布局。

页面从上到下固定结构如下：

1. 页面标题区
2. 一级分类 Tab
3. 二级媒体 Tab
4. 搜索与刷新区
5. 统计说明区
6. 资产列表区

### 4.2 页面标题区

标题区位于页面顶部，包含以下内容：

- 页面标题：`资产库`
- 页面副标题：说明该页面用于统一查看角色、场景、图片、视频、音频资产，并追踪来源

标题区不承担筛选、跳转或业务操作。

### 4.3 一级分类 Tab

一级分类 Tab 用于区分资产大类。

当前版本包含 3 个一级分类：

- `角色库`
- `场景库`
- `媒体库`

每个一级分类要求：

- 展示分类名称
- 展示当前分类数量
- 点击切换内容区
- 切换后保留搜索框

### 4.4 二级媒体 Tab

二级媒体 Tab 只在一级分类为 `媒体库` 时显示。

当前版本包含：

- `全部`
- `视频`
- `图片`
- `音频`

要求如下：

- 只在媒体库下显示
- 点击后过滤当前媒体列表
- 切换后不离开当前页面

### 4.5 搜索与刷新区

搜索与刷新区位于分类区下方。

当前版本包含：

- 搜索输入框
- 刷新按钮

搜索框占位文案按分类变化：

- 角色库：搜索角色名称、身份或描述
- 场景库：搜索场景、地点或氛围
- 媒体库：搜索标题、Provider、来源类型或项目名

刷新按钮要求：

- 点击后重新加载当前页面数据
- 刷新中需要表现加载状态

### 4.6 列表区

列表区是资产页主内容区。

不同分类下列表区结构如下：

- 角色库：角色卡片网格
- 场景库：场景卡片网格
- 媒体库：媒体卡片网格

列表区要求：

- 支持空状态
- 支持加载态
- 支持响应式多列布局

## 5. 资产分类体系

### 5.1 一级分类

资产页按以下一级分类组织：

- 角色资产
- 场景资产
- 媒体资产

### 5.2 媒体资产子分类

媒体资产按以下二级分类组织：

- 图片
- 视频
- 音频

### 5.3 当前版本资产对象范围

当前版本统一展示以下资产对象：

| 资产对象 | 是否展示 | 说明 |
|------|------|------|
| 角色 | 是 | 来自短剧项目沉淀 |
| 场景 | 是 | 来自短剧项目沉淀 |
| 图片 | 是 | 来自快速成片、短剧、画布等结果 |
| 视频 | 是 | 来自快速成片、短剧、画布等结果 |
| 音频 | 是 | 来自快速成片、短剧、画布等结果 |

当前版本不展示以下内容：

- 任务列表
- 生产中间流程
- 资产编辑表单
- 资产拖回业务模块的操作板

## 6. 卡片体系

### 6.1 角色卡片规格

角色卡片采用正方形头像卡结构。

角色卡片必须展示：

- 角色头像
- 角色名称
- 角色身份或角色类型
- 角色描述
- 所属项目
- 语音风格（如果存在）

角色卡片交互要求：

- 点击卡片图片区域时，当前版本不强制跳转
- 卡片需要有 hover 态
- 不提供“回用到短剧/画布”的按钮

### 6.2 场景卡片规格

场景卡片采用横向 16:9 图片卡结构。

场景卡片必须展示：

- 场景图
- 场景名称
- 场景时间信息
- 场景描述
- 所属项目
- 分镜数量

场景卡片交互要求：

- 点击卡片图片区域时，当前版本不强制跳转
- 卡片需要有 hover 态
- 不提供回用入口

### 6.3 媒体卡片规格

媒体卡片统一采用“预览区 + 信息区 + 操作区”的结构。

媒体卡片必须展示：

- 资产类型标签
- 来源标签
- 标题
- Provider
- 创建时间
- 来源说明

#### 图片卡片

图片卡片预览区要求：

- 直接展示图片缩略图
- 点击图片可打开大图预览

图片卡片操作区要求：

- 下载
- 打开来源
- 预览

#### 视频卡片

视频卡片预览区要求：

- 优先展示缩略图
- 无缩略图时展示视频占位图

视频卡片操作区要求：

- 下载
- 打开来源

当前版本视频卡片列表区不强制内嵌视频播放器。

#### 音频卡片

音频卡片预览区要求：

- 展示音频图形占位区
- 展示音频标题
- 展示音频类型提示

音频卡片信息区要求：

- 标题
- Provider
- 创建时间
- 来源说明

音频卡片操作区要求：

- 内嵌 `<audio controls>` 播放器
- 下载
- 打开来源

| 图片卡 | 打开大图预览 | 是 | 是 | 否 | 是 |

| 音频卡 | 无主图动作 | 是 | 是 | 是 | 否 |

## 8. 搜索与筛选规则

### 8.1 搜索规则

搜索为当前页面内过滤，不跳转页面。

搜索范围如下：

#### 角色库搜索

- 角色名称
- 角色身份
- 角色描述

#### 场景库搜索

- 场景名称
- 场景时间
- 场景描述

#### 媒体库搜索

- 资产标题
- Provider
- 来源类型
- 项目名

### 8.2 分类切换规则

- 一级分类切换后，列表内容整体切换
- 媒体二级分类切换只影响媒体库内容
- 搜索词在切换分类后保留

### 8.3 统计说明规则

搜索框下方必须展示当前统计说明。

统计文案要求：

- 展示该分类总数量
- 展示当前筛选后数量
- 如果已应用二级筛选，需注明筛选类型
- 如果已应用搜索，需注明已应用搜索

## 9. 来源体系

### 9.1 来源字段

媒体资产至少要支持以下来源字段：

- `source_type`
- `source_path`
- `drama_id`
- `episode_id`
- `storyboard_id`
- `task_id`

### 9.2 当前版本来源类型

当前版本页面需要能识别并展示以下来源类型：

| source_type | 页面文案 | 打开来源动作 |
|------|------|------|
| `quick_video` | 快速成片 | 打开快速成片 |
| `quick_image` | 快速成片 | 打开快速成片 |
| `quick_audio` | 快速成片 | 打开快速成片 |
| `drama_video` | 短剧任务 | 打开项目或短剧来源 |
| `writing` | 小说剧本 | 打开文稿 |
| `legacy_asset` | 历史资产 | 若无路径则来源不可用 |
| 其他未知来源 | 任务来源 | 若无路径则来源不可用 |

### 9.3 来源说明规则

来源说明展示优先级如下：

1. 如果能识别所属项目，优先显示 `来源项目：项目名`
2. 如果属于小说链路，显示 `来源：小说剧本导出或改编链路`
3. 如果属于快速成片链路，显示 `来源：快速成片`
4. 如果属于历史回填，显示 `来源：历史回填资产`
5. 其他情况显示 `来源：独立任务`

### 9.4 来源跳转规则

来源跳转按钮文案按来源变化：

- 打开项目
- 打开文稿
- 打开快速成片
- 打开来源
- 来源不可用

规则要求：

- 能解析链接时按钮可点击
- 无法解析来源路径时按钮禁用
- 禁用态必须显示不可用提示

## 10. 入库规则

### 10.1 快速成片入库

快速成片的图片、视频、音频结果需要进入资产。

当前版本规则：

- 图片和视频可通过 `保存到资产库` 显式入库
- 音频生成后可直接入库

### 10.2 短剧入库

短剧流程产出的角色、场景、图片、视频、音频需要进入资产。

### 10.3 画布入库

画布中沉淀的新图片、视频、音频结果需要进入资产。

### 10.4 当前版本不做

- 不在资产页内直接执行入库动作
- 不在资产页内人工新建资产
- 不在资产页内编辑资产信息

## 11. 页面状态

### 11.1 加载状态

各分类内容区在数据加载时必须展示 loading 状态。

要求如下：

- 不直接显示空白页面
- 角色、场景、媒体列表都需要有加载占位

### 11.2 空状态

不同分类的空状态文案需要区分：

#### 角色库空状态

- 默认文案：还没有收录角色，请从短剧详情中收录
- 搜索后空文案：没有符合搜索条件的角色

#### 场景库空状态

- 默认文案：还没有收录场景，请从短剧详情中收录
- 搜索后空文案：没有符合搜索条件的场景

#### 媒体库空状态

- 默认文案：当前筛选条件下还没有可展示的资产。可先快速成片，再把结果沉淀到资产。
- 必须提供 `前往快速成片` 按钮

### 11.3 失败状态

数据加载失败时：

- 弹出错误提示
- 页面保留当前结构
- 用户可点击刷新重试

## 13. 页面流转

### 13.1 进入页面

- 从侧边入口进入资产页
- 从快速成片进入资产页
- 从短剧进入资产页
- 从画布进入资产页

### 13.2 页面内流转

- 切换一级分类不离开页面
- 切换媒体二级分类不离开页面
- 搜索不离开页面
- 点击下载直接下载资源
- 点击打开来源跳转到原始上下文
- 图片预览在当前页以内置预览器打开

### 13.3 离开页面

- 来源跳转后离开资产页
- 返回上层导航后离开资产页

## 15. 验收清单

### 15.1 布局验收

- 页面是否按标题区、分类区、搜索区、列表区组织
- 一级分类和媒体二级分类是否职责清楚
- 列表区是否支持响应式卡片布局

### 15.2 数据验收

- 角色、场景、图片、视频、音频是否都能被展示
- 数量统计是否正确
- 搜索结果是否正确
- 来源文案是否正确映射

### 15.3 交互验收

- 图片是否可预览
- 音频是否可播放
- 下载按钮是否可用
- 打开来源是否正确跳转
- 来源不可用时是否正确禁用

### 15.4 状态验收

- 加载态是否正确显示
- 空状态是否按分类区分
- 刷新后是否能重新加载
- 失败提示是否明确

### 15.5 边界验收

- 页面是否没有承担回用入口
- 页面是否没有承担生成入口
- 页面是否没有承担项目管理

## 16. 当前版本边界

当前版本资产模块只做以下闭环：

- 查看角色资产
- 查看场景资产
- 查看图片、视频、音频资产
- 搜索和分类筛选
- 图片预览
- 音频播放
- 下载
- 查看来源并跳转

当前版本不扩展以下内容：

- 在资产页直接生成
- 在资产页编辑资产
- 在资产页把资产回用到业务模块
- 资产拖拽回画布或短剧

# 小窗 XIAOCHUANG - 0.23.x 版本计划

**版本**: 0.23.x
**下一交付版本**: 0.24.0
**状态**: `0.23.2` 已封版；`0.23.3` 暂缓独立排期，相关范围按短剧项目中枢需要并入 `0.24.0` 或后续版本
**版本类型**: minor train
**最后更新**: 2026-07-08

## 1. 版本定位

`0.23` 不再作为一个一次性交付的大版本推进，而拆成 `0.23.1 / 0.23.2 / 0.23.3` 三个小版本逐步落地。

拆分原则：

- 先修短剧主流程，再验收画布生产闭环。
- 先处理“用户看到的是假产物”的问题，再处理“画布产物如何沉淀和复用”的问题。
- 已经部分落地的画布能力不回滚，但不再抢占 `0.23.1` 最高优先级。
- 每个小版本只解决一个清晰主问题，避免短剧重构、画布闭环和 Agent 能力互相拖累。

`0.23.0` 作为规划包和文档列车入口，已经完成需求归档、事实入口收敛和优先级重排。

## 3. 分版本必做范围

### 3.1 `0.23.1` 短剧 AI-first

目标：优先解决短剧模块“方案草稿是规则模板，不是真实 AI 产物”的产品问题。

必做范围：

1. 删除“方案草稿”作为主流程对象。
2. 源稿导入后先形成 `source_health / source_analysis`。
3. AI 输出 2 到 3 套 `adaptation_brief`，用户选择后再进入分集蓝图。
4. AI 基于选定策略创建真实 `Episode(status=blueprint)`。
5. 分集页围绕真实 episode 工作，不再展示规则 outline。
6. 单集工作台读取 `episode.blueprint + episode.script_content`。
7. 明确项目公共主档、单集引用与覆写、镜头私有产物三层模型。
8. 项目子页优先做 `source / episodes / assets`；`strategy / settings` 视研发容量后移。

### 3.2 `0.23.2` 画布可信闭环

目标：把已经部分落地的画布资产、上传、生成历史能力补到可信验收状态。

研发优先级、封版门禁与 No-Go 以 [0.23.2研发规格任务列表.md](./0.23.2研发规格任务列表.md) 为唯一真相源；本节任务清单只作范围概述。其中「节点生成历史并发写保护」是本版本唯一真开发缺口，其余为验收补测。

封版结果见 [0.23.2封版说明.md](./0.23.2封版说明.md)。`0.23.2` 已完成可信闭环验收；后续画布 Agent 与镜头体验暂缓独立排期，按短剧项目中枢需要并入 `0.24.0` 或后续画布专项。

必做范围：

1. 画布生成结果真实写入资产体系。
2. 资产库可搜索、预览、下载画布产物。
3. 资产库可从画布产物打开来源画布。
4. 画布上传支持图片、视频、音频进入画布，并可选保存到资产。
5. 节点生成历史可见、可切换、可下载，并支持保存到资产。
6. 最小快速生成可用，结果插入为可见节点并保留来源引用。
7. 补齐画布上传、历史、资产回源的 E2E 或 API 验收。

### 3.3 `0.23.3` 画布 AI 对话与镜头体验

目标：在可信闭环稳定后，再开放最小 AI 对话代理和镜头工作区体验。

必做范围：

1. 对话栏开放 `canvas.create_nodes / update_node / add_to_context`。
2. 需确认的修改操作展示计划，用户确认后执行。
3. 角色/场景节点通过端口连线到镜头节点。
4. 合成节点吸收导出能力，导出产物按 `canvas_export` 入资产。
5. 镜头节点默认按顺序排列，角色/场景在上方，结果在下方。
6. 右侧镜头控制台和顶部进度条形成可用体验。

## 4. 可选范围

- `0.23.1` 可选：`strategy / settings` 子页完整拆分、试播正文批量 A/B、迁移旧 `adaptationPlan`。
- `0.23.2` 可选：画布运行历史列表、画布节点输出版本预览、画布产物批量入库。
- `0.23.3` 可选：更细的运行失败恢复与重试面板、对话引用节点高亮、真实 LLM 规划替代规则代理。

## 5. 不做范围

- 不做多人实时协作。
- 不做复杂分支版本合并。
- 不做画布直接覆盖短剧源数据。
- 不做画布全量替代短剧工作台。
- 不做完整时间线剪辑工具。
- `0.23.1` 不做画布 Skill 对话代理、角色/场景端口连线、合成导出节点。
- 不做模式切换（画布只有一种工作区，对话栏可收起）。
- 不做便签节点。
- `0.23.2` 不做完整画布 Agent，只做可信闭环验收。
- `0.23.3` 不做对话触发生成、删除连线、保存资产等高风险 Skill。
- 不做 0.24.0/0.25.0 Skill（delete_nodes / create_edge / delete_edge / generate / save_to_assets）。
- 不做对话跨会话保持（后续增强）。
- 不做对话回溯撤销（后续增强）。
- 不新增独立原型页。
- 不新增“方案草稿”页面、独立角色圣经页或独立场景圣经页。

## 6. 验收门禁

### 6.1 `0.23.1`

- 短剧项目详情页不再依赖“方案草稿”主面板。
- 源稿导入后可看到健康检查和 AI 理解产物。
- 用户能比较并选择 AI 改编策略。
- 分集生产页展示真实 episode blueprint。
- 至少 1 集能从 blueprint 生成试播正文并进入单集工作台。
- 单集工作台的角色、场景、配音引用逻辑能区分项目公共主档、单集引用与镜头私有产物。

### 6.2 `0.23.2`

- 从画布生成或上传结果。
- 在节点生成历史中看到该结果，并可切换当前结果。
- 在资产库找到该结果。
- 预览或下载该结果。
- 打开来源回到对应画布。
- 刷新页面后结果、来源、运行状态不丢失。

### 6.3 `0.23.3`

- 对话创建节点：用户说“加一个镜头”，AI 调用 `canvas.create_nodes`，节点出现在画布。
- 对话修改节点：用户说“改成雨夜近景”，AI 调用 `canvas.update_node`，确认后目标节点更新。
- 对话加入上下文：用户说“看一下这个角色”，AI 调用 `canvas.add_to_context`，角色信息进入对话上下文。
- 角色节点可通过端口连线到镜头节点的角色输入端口。
- 场景节点可通过端口连线到镜头节点的场景输入端口。
- 合成导出节点可触发导出，导出产物可沉淀为资产。

## 7. 研发任务清单

### 0.23.2 / P0 - 画布资产闭环

目标：画布生成结果和历史结果可以真实进入资产库，并能从资产库回到来源画布。

后端任务：

1. 新增 `assets.source_ref` text nullable 字段，用于保存 `canvas_id`。
2. 扩展资产来源类型：`canvas_upload / canvas_generation / canvas_export / canvas_history`。
3. 实现 `CanvasAssetService`。
4. 实现 `POST /api/v1/canvases/:id/assets`。
5. 支持同一 `canvas_id + node_id + result_id` 幂等保存。
6. 保存成功后回写节点 `results[].asset_id`。

前端任务：

1. 节点右键和历史面板接入 `保存选中结果到资产`。
2. 已保存结果展示资产状态。
3. 资产库支持展示、搜索、预览、下载画布来源资产。
4. 资产详情或列表支持“打开来源画布”。

验收：

1. 画布结果保存后资产库可见。
2. 资产可预览或下载。
3. 从资产来源可回到对应画布。
4. 刷新后资产来源和节点资产状态不丢失。

### 0.23.2 / P1 - 画布上传闭环

目标：画布上传真实可用，上传后生成节点，按用户选择决定是否入资产。

后端任务：

1. 实现 `CanvasUploadService`。
2. 实现 `POST /api/v1/canvases/:id/uploads`。
3. 支持图片、视频、音频上传的 mime 白名单和分档大小限制（图片 30MB / 视频 200MB / 音频 100MB，顶层硬上限 200MB）。
4. 上传默认只进入画布，不自动入资产。
5. `save_to_assets=true` 时同步创建资产记录。

前端任务：

1. 空白右键 `上传` 接入 `CanvasUploadDialog`。
2. 上传图片创建 `image` 节点。
3. 上传视频创建 `video-asset` 节点。
4. 上传音频创建 `audio` 节点。
5. 上传弹层支持“同时保存到资产”选项。

验收：

1. 上传真实文件后画布出现节点。
2. 刷新后上传节点仍存在。
3. 勾选保存到资产后，资产库出现对应资产。

### 0.23.2 / P2 - 画布生成历史

目标：节点生成结果可沉淀为历史，用户可以切换、下载、保存历史结果。

后端任务：

1. 实现 `CanvasNodeResultService`。
2. 节点 `data_json.results` 支持追加结果。
3. 节点 `current_result_id` 标记当前结果。
4. 每个节点最多保留 20 条结果。
5. 支持查询节点历史和选择历史结果。
6. 并发生成时不得丢失结果（读-改-写必须包 transaction，采用行锁或乐观锁；当前实现缺失，为 0.23.2 P0）。

前端任务：

1. 实现 `NodeResultHistoryPanel`。
2. 节点右键 `查看生成历史` 打开历史面板。
3. 历史结果支持选择为当前结果。
4. 历史结果支持下载。
5. 历史结果支持保存到资产。

验收：

1. 同一节点连续生成多次后可看到多条历史。
2. 选择历史后节点预览切换。
3. 刷新后当前历史选择保持。
4. 历史结果可下载、可保存资产。

### 0.23.2 / P3 - 画布最小快速生成

目标：用户可从空白提示词或单节点触发快速生成，生成结果插入为可见节点。

后端任务：

1. 扩展 `POST /api/v1/canvases/:id/business-action`。
2. 支持 `output_mode=insert_new_node`。
3. 支持 `position_x / position_y` 作为新节点插入位置。
4. 生成结果写入新节点 `results`。
5. 新节点写入 `references`，记录来源节点或来源资产。

前端任务：

1. 实现 `QuickGenerateDialog`。
2. 空白右键快速生成支持输入提示词。
3. 单节点右键快速生成支持基于当前节点生成。
4. 前端计算新节点位置：空白生成插入当前视野中心，单节点生成插入来源节点右侧。

验收：

1. 空白快速生成后画布出现结果节点。
2. 单节点快速生成后新节点包含来源引用。
3. 生成结果进入历史。
4. 刷新后新节点和当前结果仍存在。

### 0.23.3 / P0 - Skill 驱动 AI 对话代理最小闭环

目标：对话栏拥有完整画布上下文，`0.23.3` 只开放 3 个 Skill：`create_nodes / update_node / add_to_context`。

验收：

2. 用户说“帮我生成 5 个镜头”，AI 创建 3-5 个镜头草稿节点。

4. 用户说“看一下这个角色”，角色信息进入对话上下文。

### 0.23.1 / P0 - 短剧 AI-first 改编流程重构

目标：把短剧项目从“小说源稿 -> 方案草稿 -> 分集制作”的伪规划链路，调整为“源稿理解 -> 改编策略 -> 分集蓝图 -> 试播正文 -> 单集工作台生产”的真实 AI 产物链路。

产品任务：

1. 删除“方案草稿”作为主流程对象。
2. 将 `/drama/[id]` 改为项目概览驾驶舱。
3. 新增 `/drama/[id]/source`，承接源稿导入、健康检查和 AI 源稿理解。
4. 新增或内嵌 `/drama/[id]/strategy` 能力，承接改编策略生成、比较、编辑和选择；若研发容量不足，可先内嵌在项目详情或分集生产页。
5. 新增 `/drama/[id]/episodes`，承接分集蓝图、试播正文、批量生成和失败重跑。
6. 新增 `/drama/[id]/assets`，承接项目公共角色、公共场景、音色、单集覆写和镜头产物治理。
7. 新增或后移 `/drama/[id]/settings`，承接项目级模型、画风、配音、发布偏好和提示词约束；`0.23.1` 不强制独立成页。
8. 保持 `/drama/[id]/episode/[episodeNumber]` 为单集工作台，但增加公共资产引用、候选合并、作用域选择和依赖检查。

数据任务：

1. 新增或规划 `source_analysis`、`adaptation_brief`、`episode.blueprint_payload`、`episode.source_trace`。
2. 明确 `characters` 为项目级角色主档。
3. 明确 `episode_characters` 为单集角色引用关系。
4. 明确 `scenes.scope = drama | episode` 和 `scenes.master_scene_id` 的迁移方向。
5. 给 `episode_characters`、`episode_scenes` 增加 `override_payload` 的设计预留。
6. 给 `storyboards` 增加 `render_snapshot` 的设计预留，记录镜头生成时使用的资产版本。

验收：

1. 短剧项目主流程不再展示“方案草稿”主面板。
2. 源稿导入后可看到源稿健康检查和 AI 理解结果。
3. 用户可生成、比较并选择至少 2 套改编策略。
4. 系统基于选定策略创建真实 episode blueprint。
5. 至少 1 集可从 blueprint 生成试播正文并进入单集工作台。
6. 单集工作台能区分项目公共主档、单集引用/覆写、镜头私有产物。

## 8. 测试计划

`0.23.1` 短剧测试：

1. `drama-ai-first-source.spec.ts`：源稿导入、健康检查、AI 理解结果展示。

# 0.23.2 封版说明

版本：`0.23.2`
日期：`2026-07-07`
状态：已完成，可封版
主线：画布可信闭环验收版

## 1. 封版结论

`0.23.2` 已完成研发规格中定义的封版门禁，可以作为“画布可信闭环验收版”封版。

本版本不是大范围新增功能版本，而是对 `0.23.1` 已落地画布能力进行可信闭环补强：补齐节点生成历史并发写保护、统一画布资产来源口径，并用后端单测与 Canvas E2E 固化“生成或上传 -> 节点历史 -> 资产库 -> 预览/下载 -> 回源画布 -> 刷新不丢”的验收链路。

## 2. 封版范围

本次封版覆盖以下 `0.23.2` 范围：

1. 节点生成历史并发写保护。
2. 画布资产来源类型收敛与资产闭环验收。
3. 画布上传分档限制、失败提示与上传入资产验收。
4. 节点历史面板追加、切换、下载、保存资产与刷新保持验收。
5. 空白快速生成与节点右键快速生成最小链路验收。
6. 快速生成产品口径修订：默认进入节点历史，不自动进入资产；保存资产由用户显式触发。

以下能力不进入 `0.23.2` 封版范围，继续进入后续版本：

1. 多人实时协作。
2. 复杂分支版本合并。
3. 完整时间线剪辑工具。
4. 画布 Skill 对话代理、角色/场景端口连线、合成导出节点。
5. 完整 8 个画布 Skill。
6. 画布直接覆盖短剧源数据。

## 3. 研发完成项

### R232-01 节点生成历史并发写保护

已完成。

- `appendResult / selectResult / markAssetId` 的读-改-写已进入事务。
- 事务内锁定目标 `canvas_nodes` 行，避免并发 append 产生 last-write-wins 覆盖。
- 保留 20 条结果上限，并保证 `current_result_id` 指向有效结果。
- 新增并发追加、追加与选择交叉执行等后端单测。

### R232-02 画布资产闭环验收

已完成。

- 新增画布资产来源类型常量，收敛 `canvas_upload / canvas_generation / canvas_export / canvas_history` 应用层取值。
- 历史结果保存到资产库时正确标记 `canvas_history`。
- 上传入资产时正确标记 `canvas_upload`。
- 资产库加载绕过旧缓存，保证从画布保存资产后进入资产库可见。
- E2E 覆盖从历史保存资产、资产库展示来源、打开来源画布并定位节点。

### R232-03 画布上传闭环验收

已完成。

- 上传大小限制按分档口径固定：图片 30MB、视频 200MB、音频 100MB。
- 后端单测覆盖类型与大小边界。
- E2E 覆盖上传入资产和非法类型、超限失败提示。

### R232-04 画布生成历史验收

已完成。

- 新增 `canvas-node-result.service.test.ts`，覆盖追加、20 条截断、选择当前结果、资产回写、并发写保护。
- 新增节点历史 E2E，覆盖历史可见、切换预览、刷新保持、下载入口、保存资产、资产回源。

### R232-05 最小快速生成验收

已完成。

- 空白右键快速生成会在右键位置或视野中心插入结果节点。
- 单节点右键快速生成会在来源节点右侧插入结果节点。
- 新节点记录来源引用。
- 生成结果默认进入节点历史，不自动进入资产。
- E2E 覆盖快速生成结果可见、进入历史、刷新不丢、来源引用与位置关系。

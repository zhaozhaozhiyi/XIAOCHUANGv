# 小窗 XIAOCHUANG 0.23.2 发布说明

**版本**: `0.23.2`
**状态**: 已封版
**发布日期**: 2026-07-07
**上一版本**: `0.23.1`
**下一版本**: `0.24.0`

## 1. 版本定位

`0.23.2` 是画布可信闭环验收版。

本版本不是大范围新增功能，而是把 `0.23.1` 已落地的画布能力补成可验收、可回归的闭环：生成或上传结果 -> 节点历史 -> 资产库 -> 预览/下载 -> 回源画布 -> 刷新不丢。

## 2. 主要更新

| 范围 | 更新 |
|------|------|
| 节点生成历史 | `appendResult / selectResult / markAssetId` 读改写进入事务，并锁定目标 `canvas_nodes` 行，避免并发覆盖 |
| 资产闭环 | 收敛 `canvas_upload / canvas_generation / canvas_export / canvas_history` 来源类型，支持资产库展示、筛选和回源 |
| 上传闭环 | 固定图片 30MB、视频 200MB、音频 100MB 的分档限制，并覆盖失败提示与入资产验收 |
| 历史面板 | 支持历史追加、切换预览、刷新保持、下载入口、保存资产和资产回源 |
| 快速生成 | 空白右键与单节点右键快速生成结果默认进入节点历史，不自动进入资产 |
| 测试补齐 | 新增 `canvas-node-result.service.test.ts` 与 Canvas E2E `06-node-result-history`、`07-minimum-quick-generate` |

## 4. 已知风险与后续计划

| 风险 | 等级 | 处理计划 |
|------|------|----------|
| `source_type` 仍是应用层常量收敛，未加 DB 级枚举或约束 | Low | 后续版本评估是否补数据库约束 |
| AI-first 长篇分块、字段漂移和真实 API 失败样本回归未纳入本次封版阻塞 | Medium | 后续作为专项回归沉淀 |
| 画布 Skill 对话代理、角色/场景端口连线、合成导出节点尚未收口 | Medium | `0.23.3` 暂缓独立排期，按短剧项目中枢需要并入 `0.24.0` 或后续版本 |

## 5. 后续承接方向

原 `0.23.3` 的画布 AI 对话与镜头体验增强范围暂缓独立排期，后续按短剧项目中枢需要并入 `0.24.0` 或后续画布专项：

- 开放 `create_nodes / update_node / add_to_context` 三个最小 Skill。
- 修改类操作先展示计划，用户确认后执行。
- 角色/场景节点通过端口连线进入镜头上下文。
- 合成节点吸收导出能力，导出产物按 `canvas_export` 入资产。
- 镜头节点排序、右侧控制台和顶部进度形成更清晰的工作流。

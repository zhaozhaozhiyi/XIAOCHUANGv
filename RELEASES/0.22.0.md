# 小窗 XIAOCHUANG 0.22.0 发布说明

**版本**: `0.22.0`
**状态**: 当前版本
**发布日期**: 2026-07-04
**上一版本**: `0.21.1`
**下一版本**: `0.23.0`

## 1. 版本定位

`0.22.0` 是在 `0.21.1` 稳定基线之上的验收与产品逻辑收口版本。

本版本不扩展新模块，重点把首页、短剧、小说源稿、AI 调用和媒体任务链路整理成更适合真实用户理解、测试和交付的状态。

## 2. 产品迭代重点

| 方向 | 迭代内容 | 用户价值 |
|------|----------|----------|
| 首页入口 | 首页继续承担主要创作入口，项目卡片显示更准确的进度、集数和源稿异常状态 | 用户能更快判断项目当前处于哪一步 |
| 短剧列表 | 创建短剧时保留失败输入、补充错误提示，列表卡片显示源稿异常 | 降低创建失败后的重复输入成本 |
| 短剧详情 | 支持小说/原稿导入、源稿健康检查、目标集数/节奏/风格设置、方案草稿预览 | 让“原稿 -> 短剧项目 -> 分集制作”形成更完整闭环 |
| 方案草稿 | 将“生成改编方案”收口为“生成方案草稿”，明确该步骤是本地规则草稿，不冒充 AI 调用 | 产品预期更诚实，减少用户误解 |
| 分集生成 | 可从方案草稿批量生成分集初稿，再进入单集工作台做 AI 改写、分镜和媒体生产 | 把结构规划和 AI 生产拆开，减少失败成本 |
| AI 调用 | 新增 AI/媒体错误文案，对配置缺失、参考图不可下载、服务商拦截、网络超时等场景给出下一步建议 | 用户知道该配置、重试、换图还是去任务中心 |
| 媒体任务 | 批量图片、视频、配音、合成等长任务的超时提示更接近真实队列状态 | 避免“任务还在跑但页面说失败”的挫败感 |

## 3. 工程迭代重点

| 方向 | 迭代内容 |
|------|----------|
| 版本治理 | 根目录新增 `VERSION_PLAN.md`，固定当前版 `0.22.0`、上一版 `0.21.1`、下一版 `0.23.0` |
| 包版本 | root、web、backend、admin、shared packages 统一升级到 `0.22.0` |
| 元数据模型 | 扩展短剧 metadata，支持项目默认 AI 配置、小说源稿、方案草稿、角色/场景 Bible 和分集 outline |
| 状态判断 | 新增短剧产品状态工具，统一计算集数、画幅、项目进度和源稿健康状态 |
| 错误解释 | 新增 AI 错误翻译工具，前端工作台和宫格工具复用同一套错误说明 |
| 文案修复 | 修复小说导出 Markdown 中的乱码标题和空白文档提示 |

## 4. 与 `0.21.1` 的主要差异

| 模块 | `0.21.1` | `0.22.0` |
|------|----------|----------|
| 版本目标 | 稳定性与文档同步 patch | 验收与产品逻辑收口 minor |
| 首页 | 承接创作入口，替代独立 `/create` 聚合页 | 增强项目进度、集数和源稿异常提示 |
| 短剧 | 以项目、分集、角色、场景、制作入口为主 | 增加源稿导入、方案草稿、分集生成前置规划 |
| AI Runtime | 统一 Skill 驱动、任务落库与恢复 | 明确哪些步骤真正调用 AI，增强配置前置检查和失败原因翻译 |
| 媒体任务 | 长任务状态可恢复、失败可重试 | 长任务失败/超时文案更贴近队列实际状态 |
| 版本文档 | `newdocs` 中维护版本说明 | 根目录新增 GitHub 可见的版本规划和发布说明 |

## 5. 已知风险与后续计划

| 风险 | 等级 | 处理计划 |
|------|------|----------|
| 外部 AI 服务商无法访问本地 `127.0.0.1/static` 媒体 URL 时，图生视频参考图可能失败 | Medium | `0.22.x` 先给出清晰提示，`0.23.0` 结合对象存储闭环强化 |
| 方案草稿当前是规则生成，不是 AI 改编 | Low | 后续可评估接入文本 AI 生成正式改编方案 |
| 画布上传、保存到资产、资产回源尚未完全实证 | Medium | 进入 `0.23.0` 主线 |

## 7. 后续版本

`0.23.0` 聚焦画布与资产闭环增强：

- 画布产物真实写入资产库。
- 上传图片/视频/音频真实进入画布，可选择保存资产。
- 资产库可打开来源画布。
- 节点生成历史可见、可切换、可下载、可保存资产。
- 画布对话栏开放最小 Skill：创建节点、修改节点、加入上下文。
